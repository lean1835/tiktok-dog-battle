# TikTok gift artwork

Actual gift thumbnails were obtained from TikTok webcast CDN URLs listed in:
https://github.com/antiops/tiktok-trending-data/blob/main/live-gift-details.json

Retrieved 2026-11-04. The bundled 28 transparent WebP thumbnails are at most 96 × 96 px. `manifest.json` records the source CDN URL and source/output SHA-256 for each gift ID. Artwork belongs to TikTok/ByteDance; it is used to identify actual TikTok gifts, and is not labeled CC0 or original artwork. This game is not endorsed by TikTok. The source catalog is a reference for image identity; LIVE coin values still come from received event metadata or the operator's explicit fallback rules.
